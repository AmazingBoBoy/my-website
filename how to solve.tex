\begin{enumerate}
    \item Look at a certain statement or problem from different perspectives. For example: the following statements are equivalent:
    \[p\mid t^n-1\]
    \[\text{t is a root of } x^n-1 \pmod{p}\]
    \[\text{the order of t modulo p divides n}\]
    \item Seek the relationship between objects and morphism. How to turn an object into a morphism and vice versa.
    \[\text{Given a group of automorphisms, we can look at the set of objects fixed by the morphism}\]
    \[\text{Given a set of objects, we can look at the group of morphisms that fix them}\]
    \[\text{An element in a field extension k to F can be seen as a linear transformation of F vector space over k}\]
    \item Look for the generalized version to dismiss the redundant information.
    \item Create new definition and play with it to see how it fits into the problems.
    \item Create extra objects and see how they interact with the existing objects. 
\end{enumerate}
